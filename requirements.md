## Mocktale
Mocktale is a api mocking tool for developers to mock api responses and to test their applications.

## Tech Stack
- ExpressJS
- NodeJS
- SQlite
- Swagger

### Workflow
1. User creates a project in the mocktale application.
2. User can add mock api's to the project. appended to project id/{api-name}
3. User can test the mock api's.
4. User can export the mock api's as a json file.
5. User can import the mock api's from a json file.
6. User can delete the mock api's.
7. User can delete the project.
8. User can view the projects
9. User can view the api's in the project
10. User can view the api's response in the project
11. User can edit the api's response in the project


### Services
Services folder will have all the services related to the application.

### UI
UI folder will have all the ui related to the application. This UI is built using Vite + React + TailwindCSS + Axios
